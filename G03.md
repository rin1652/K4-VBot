## Slide 1 — Giả định tải và lựa chọn cloud

- 2,000 DAU × 22 × 40 = 1.76M request/tháng.
- Weighted request: 3,800 input token và 560 output token.
- 6.688B input + 0.986B output token/tháng.
- Giờ hành chính: 220h/tháng; trung bình 2.22 req/s; đỉnh 3x = 6.67 req/s.
- Sandbox: 400k × 30s = 3,333 task-hours/tháng; ảnh 90k/tháng; workspace 6TB.
- AWS ap-southeast-1, 2 AZ: độ trễ gần người dùng Việt Nam, dịch vụ managed sẵn, failover rõ.
- Bedrock API: tránh GPU luôn bật; Nova Lite cho Cấp 1–3, Nova Pro cho Cấp 4–5; private path + cam kết không dùng dữ liệu huấn luyện.
- TOTAL: 11,674.74 USD/tháng, 5.84 USD/DAU/tháng, chưa VAT.

## Slide 2 — Kiến trúc, bảo vệ và luồng một request

- User → SSO/MFA → WAF → ALB multi-AZ → Fargate app → API/LLM gateway.
- Gateway route theo cấp: Bedrock; connector OAuth; pgvector ACL filter; S3 workspace.
- Agent code: Fargate sandbox, 30s TTL, task role tối thiểu, chặn egress và metadata endpoint.
- H2/H3: workspace prefix + KMS, vector query lọc ACL, token connector trong Secrets Manager.
- H4/H5: prompt injection isolation, guardrail/DLP, user confirmation trước hành động ghi, audit 12 tháng.
- H6/H7: streaming token, background queue, multi-AZ ALB/Aurora/ElastiCache, daily backup, RTO 4h/RPO 1h.
- H8: eval gate theo 5 cấp, quota/user và budget alert; khi vượt ngân sách giảm model/queue ưu tiên thấp.
- Tiết kiệm chính: API token theo tải, Fargate scale-to-zero sandbox, pgvector trong Aurora, S3 lifecycle.

## Trả lời sẵn cho hội đồng

1. **Agent A có đọc file B không?** Không. Mỗi workspace có prefix và KMS policy riêng; connector token gắn user; retrieval luôn lọc ACL theo quyền gốc trước khi gọi model; sandbox chỉ mount workspace của request.

2. **Email có prompt injection yêu cầu gửi hợp đồng ra ngoài?** Nội dung connector là untrusted context; policy engine tách chỉ dẫn khỏi dữ liệu, DLP kiểm tra đích và loại dữ liệu, hành động gửi email cần người dùng xác nhận. Sandbox không có egress.

3. **DAU tăng lên 4,000?** Bedrock, gateway, SQS, storage và egress tăng gần tuyến tính; Fargate app scale theo p95/queue depth; Aurora/ElastiCache tăng replica khi vượt ngưỡng. Trước khi tăng tài nguyên, quota và routing chuyển Cấp 1–3 sang Nova Lite để giữ ngân sách.
