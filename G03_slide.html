Data boundaries

Connector content is untrusted. ACL được lọc trước top-K và kiểm tra lại trước download. OAuth token chỉ ở dạng ciphertext.

Side effects

send_email / create_ticket / delete_file cần approval nonce. Sandbox chỉ nhận input đã được phân quyền.

Vì sao API thay vì GPU/hybrid

Định hướng chi phí thấp nhất với tải bursty và chưa có throughput GPU đo được

Bedrock API · baseline

  • Không giữ GPU 24/7
  • Chi phí gắn model calls/token
  • Scale theo request và peak
  • Private endpoint + APAC routing

GPU/hybrid · chưa chốt

  • Cần giá GPU và throughput thực đo
  • Cộng replica HA, storage, network và vận hành
  • Chỉ chọn khi total GPU < API và đạt H6/H8
